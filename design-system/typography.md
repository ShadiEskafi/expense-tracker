# نظام الخطوط والطباعة — Typography

> **الهدف**: تحديد عائلة الخطوط العربية، المقياس الطباعي الهرمي، ومعايير عرض الأرقام والمبالغ المالية لضمان أقصى درجات الوضوح والراحة البصرية.

---

## 1. عائلة الخط الأساسية (Primary Font Family)

الخط المعتمد رسمياً للتطبيق هو **IBM Plex Sans Arabic**، مع حزمة احتياطية نظامية:

```css
:root {
  --font-family-arabic: 'IBM Plex Sans Arabic', -apple-system, BlinkMacSystemFont, 'Segoe UI', Tahoma, Arial, sans-serif;
  --font-family-base: var(--font-family-arabic);
}
```

### أسباب اختيار `IBM Plex Sans Arabic`:
1. **وضوح هندسي نقي**: صُمم الخط للواجهات التقنية والرقمية المزدحمة بالبيانات دون زوائد خطية معقدة.
2. **استقرار الأرقام اللاتينية والعربية**: يوفر تبايناً حاداً للأرقام والنسب المئوية مع الحفاظ على ترابط الحروف العربية الطبيعي.
3. **أوزان غنية ومتوازنة**: يدعم التدرج من Regular (400) إلى ExtraBold (800) مع الحفاظ على قراءة سليمة في الأحجام الصغيرة جداً.

---

## 2. قواعد عرض الأرقام المالية (Tabular Financial Figures)

في الواجهات المالية، يجب ألا تتأرجح الأرقام أفقياً عند تغير القيم في الجداول والقوائم. لذلك يُلزم النظام بتفعيل خاصية **الأرقام الجدولية ذات العرض الثابت (Tabular Figures)**:

```css
.financial-num {
  font-feature-settings: "tnum" 1, "lnum" 1;
  font-variant-numeric: tabular-nums;
  letter-spacing: -0.01em;
  direction: ltr; /* المحافظة على التنسيق الرياضي الرقمي من اليسار لليمين */
  display: inline-block;
}
```

### شكل الأرقام وتنسيق العملة:
- تستخدم **الأرقام العربية القياسية (Western Arabic Digits: 1, 2, 3...)** المعتمدة في كافة التطبيقات المصرفية الحديثة في الشرق الأوسط (السعودية، الإمارات، مصر...).
- توضع فواصل الآلاف القياسية (كومة خفيفة) لتسهيل قراءة المبالغ الكبيرة: `12,450.00`.
- يوضع رمز العملة بعد المبلغ في سياق الجملة العربية، مفصولاً بمسافة غير قابلة للكسر: `12,450.00 ر.س` أو `450.00 $`.

## 3. المقياس الهرمي للنصوص (Type Scale)

| المستوى | الحجم (الموبايل / الديسكتوب) | الوزن | الارتفاع (Line Height) | الاستخدام الأساسي |
|---|---|---|---|---|
| **Display / Hero** | `32px` / `40px` | 800 (ExtraBold) | `1.2` | صافي المركز المالي الإجمالي في أعلى لوحة التحكم |
| **Heading 1 (H1)** | `24px` / `28px` | 700 (Bold) | `1.25` | عناوين الشاشات الرئيسية (المعاملات، التقارير) |
| **Heading 2 (H2)** | `18px` / `20px` | 700 (Bold) | `1.3` | عناوين البطاقات والأقسام (آخر المعاملات، الحسابات) |
| **Heading 3 (H3)** | `16px` / `17px` | 600 (SemiBold) | `1.35` | أسماء الحسابات، تصنيفات التقارير |
| **Body Large** | `16px` / `18px` | 600 (SemiBold) | `1.4` | مبالغ المعاملات الفردية، حقل إدخال المبلغ |
| **Body Base** | `14px` / `15px` | 400 (Regular) | `1.5` | نصوص الوصف، الملاحظات، عناصر القوائم |
| **Label / Medium**| `13px` / `14px` | 500 (Medium) | `1.4` | تسميات حقول النماذج، أزرار التصفية، الشارات |
| **Caption** | `12px` / `13px` | 400 (Regular) | `1.4` | التواريخ، النصوص التوضيحية المساعدة، نسب التغير |
| **Micro** | `11px` / `11px` | 600 (SemiBold) | `1.3` | شارات الحالة (متزامن، قيد الانتظار)، الوسوم المصغرة |

## 4. فئات المساعدة الطباعية في CSS

```css
/* الأنماط القياسية المعرفة في التصميم */
.text-display {
  font-size: clamp(32px, 4vw, 40px);
  font-weight: 800;
  line-height: 1.2;
}

.text-h1 {
  font-size: clamp(22px, 3vw, 28px);
  font-weight: 700;
  line-height: 1.25;
}

.text-h2 {
  font-size: clamp(18px, 2.5vw, 20px);
  font-weight: 700;
  line-height: 1.3;
}

.text-h3 {
  font-size: 16px;
  font-weight: 600;
  line-height: 1.35;
}

.text-body {
  font-size: 14px;
  font-weight: 400;
  line-height: 1.5;
}

.text-caption {
  font-size: 12px;
  font-weight: 400;
  line-height: 1.4;
  color: var(--color-text-secondary);
}

.text-micro {
  font-size: 11px;
  font-weight: 600;
  line-height: 1.3;
}
```
