# دليل الكتابة وتجربة المحتوى العربي — Arabic UX Content Guidelines

> **الهدف**: تحديد نبرة الصوت (Tone of Voice)، أسلوب صياغة النصوص والأزرار، وتوحيد المصطلحات المالية لضمان لغة عربية سليمة، طبيعية، ومريحة للاستخدام اليومي.

---

## 1. نبرة الصوت والأسلوب التعبيري (Tone of Voice)

1. **واضحة ومباشرة (Clear & Direct)**: نستخدم كلمات محددة وموجزة تعبر عن الإجراء المطلوب دون لف أو دوران.
2. **هادئة ومطمئنة (Calm & Reassuring)**: إدارة المال قد تكون مصدراً للتوتر، لذلك نتجنب إشعار المستخدم بالذعر أو استخدام لغة توبيخية عند زيادة المصاريف أو وجود ديون.
3. **غير بيروقراطية (Unbureaucratic)**: نتجنب تماماً مصطلحات البنوك المعقدة مثل «قيد دائن»، «قيد مدين»، «التسوية المصرفية»، ونستبدلها بكلمات بديهية مثل «دخل»، «مصروف»، «تحويل».
4. **عربية سليمة دون تقعر (Natural Arabic)**: لغة عربية معاصرة فصيحة يفهمها أي مستخدم عربي في أي بلد، خالية من العاميات المحلية أو الترجمات الحرفية الركيكة عن الإنجليزية.

---

## 2. قواعد صياغة الأزرار والإجراءات (Action Buttons)

تُصاغ الأزرار دائماً بصيغة الفعل الصريح أو المصدر المباشر الذي يوضح ما سيحدث عند الضغط:

| الإجراء بالإنجليزية | الصياغة العربية المعتمدة | صياغات ممنوعة أو غير مفضلة |
|---|---|---|
| Save Expense | **حفظ المصروف** | تسجيل أو أوكي أو تم |
| Save Income | **حفظ الدخل** | حفظ أو إضافة فقط |
| Confirm Transfer | **تأكيد التحويل** | أرسل أو نفذ |
| Quick Add | **تسجيل سريع** | إضافة سريعة أو جديد |
| Delete Transaction | **حذف المعاملة** | مسح أو إزالة |
| Sync Now | **زامِن الآن** | تزامن أو مزامنة الآن |
| Export CSV | **تصدير كملف CSV** | إخراج البيانات |
| Download Backup | **تحميل نسخة احتياطية** | بيك أب أو تصدير النسخة |
| Restore Backup | **استعادة نسخة احتياطية** | استرجاع |
| Clear All Filters | **إعادة ضبط الفلاتر** | مسح الكل |

## 3. صياغة رسائل الأخطاء والتنبيهات (Error & Validation Copy)

### قواعد أساسية:
- لا تلم المستخدم أبداً («أنت أخطأت» ❌).
- اشرح المشكلة وقدم الحل مباشرة في نفس الجملة.

| الحالة | الصياغة الصحيحة المعتمدة | الصياغة الخاطئة الممنوعة |
|---|---|---|
| حقل المبلغ فارغ أو صفر | **«يرجى كتابة مبلغ أكبر من الصفر»** | «حقل مطلوب» أو «قيمة غير صالحة» |
| لم يتم تحديد تصنيف | **«اختر تصنيفاً للمصروف للمتابعة»** | «التصنيف إلزامي» |
| التحويل لنفس الحساب | **«يرجى اختيار حسابين مختلفين للتحويل»** | «خطأ: الحساب المصدر مطابق للوجهة» |
| فشل الاتصال بالسحابة | **«تعذر الاتصال بالسحابة؛ بياناتك محفوظة بأمان على جهازك وسنعاود المحاولة لاحقاً»** | «Error 500: Sync failed» |
| امتلاء مساحة التخزين | **«مساحة تخزين المتصفح ممتلئة؛ ننصح بتحميل نسخة احتياطية وحذف السجلات القديمة»** | «Quota Exceeded Exception» |

## 4. قاموس المصطلحات المعتمدة (Financial Terminology Glossary)

يجب الالتزام الحرفي بهذه المصطلحات عبر كافة شاشات وأكواد التطبيق:

| المصطلح المعتمد بالعربية | المصطلح الإنجليزي المقابل | التعريف وسياق الاستخدام في التطبيق |
|---|---|---|
| **مصروف** | Expense | أي خروج للأموال من حسابات المستخدم لشراء سلعة أو خدمة |
| **دخل** | Income | أي دخول لأموال جديدة إلى حسابات المستخدم (راتب، مكافأة، أرباح) |
| **تحويل داخلي** | Internal Transfer | نقل مبلغ مالي من حساب لآخر يملكه نفس المستخدم (دون زيادة أو نقصان مالي) |
| **معاملة** | Transaction | المصطلح الجامع للمصروف والدخل والتحويل في سجل الحسابات |
| **الأموال المتاحة** | Available Funds | مجموع الأرصدة النقدية الحرة السائلة (كاش، بنك، محافظ) |
| **الالتزامات والديون** | Liabilities / Debt | المبالغ المستحقة السداد على بطاقات الائتمان |
| **صافي المركز المالي** | Net Financial Position | حاصل طرح الالتزامات من إجمالي الأموال السائلة المتاحة |
| **صافي التدفق النقدي**| Net Cash Flow | الفائض أو العجز الشهري (إجمالي الدخل ناقص إجمالي المصاريف) |
| **محفظة / حساب** | Account / Wallet | الوعاء المالي الذي يحفظ الرصيد (كاش، بنك، محفظة إلكترونية، بطاقة) |
| **تصنيف** | Category | الباب الذي تندرج تحته النفقات (طعام، سكن، مواصلات) |
| **وسم / وسوم** | Tag / Tags | علامة تصنيفية فرعية مرنة (مثل: #سفر، #عمل) |
| **متزامن** | Synced | حالة مطابقة البيانات المحلية مع قاعدة بيانات السحابة |
| **غير متصل** | Offline | حالة عمل التطبيق بدون اتصال بالإنترنت مع حفظ البيانات محلياً |
| **تعديلات معلقة** | Pending Changes | عمليات تمت أوفلاين وتنتظر الاتصال ليتم رفعها |
| **نسخة احتياطية** | Backup | ملف JSON كامل يحوي كافة حسابات ومعاملات وتصنيفات المستخدم |
| **استعادة** | Restore | إعادة شحن بيانات التطبيق من ملف نسخة احتياطية سابقة |
| **وضع الضيف المحلي** | Guest Mode | استخدام التطبيق محلياً على الجهاز دون الحاجة لإنشاء حساب سحابي |
