# تمثيل البيانات والرسوم البيانية — Data Visualization

> **الهدف**: تحديد القواعد الهندسية والبصرية لتحويل الأرقام المالية إلى رؤى بصرية بديهية وسهلة الفهم دون تعقيد أو تضليل، مع توفير بدائل نصية ميسرة وفق معايير الإتاحة.

---

## 1. بطاقات المؤشرات المالية الرئيسية (Financial KPI Cards)

في الجزء العلوي من لوحة التحكم، تُعرض 4 مؤشرات أساسية تمثل الحقيقة المالية للمستخدم:

```text
+-----------------------+ +-----------------------+ +-----------------------+
|  الأموال السائلة المتاحة  | |  الالتزامات والديون   | |  صافي المركز المالي   |
|     14,250.00 ر.س     | |      1,800.00 ر.س     | |     12,450.00 ر.س     |
|  (كاش + بنك + محافظ)  | |  (مستحق بطاقات ائتمان)| |  (الأصول - الالتزامات)|
+-----------------------+ +-----------------------+ +-----------------------+
+-----------------------+ +-----------------------+
|      مصاريف الشهر     | |       دخل الشهر       |
|      4,320.00 ر.س     | |      8,500.00 ر.س     |
|   (▼ 12% عن الشهر الماضي) | |      صافي الفائض: +4,180 |
+-----------------------+ +-----------------------+
```

### قواعد العرض:
1. **الأموال المتاحة (Available Funds)**: تبرز الرصيد النقدي الحر المتاح للصرف فوراً.
2. **الالتزامات (Liabilities)**: مستحقات بطاقات الائتمان بلون كهرماني متزن مع وسم صريح («مستحق السداد»)، ولا تُدمج مع الأموال السائلة.
3. **صافي المركز المالي (Net Position)**: الفرق الدقيق بين ما تملكه وما تدين به.
4. **مقارنة الشهر السابق (MoM Delta)**: مؤشر نسبة التغير يعرض:
   - انخفاض المصروف: سهم لأسفل مع نسبة مئوية بالأخضر (مؤشر إيجابي: وفرت أكثر).
   - ارتفاع المصروف: سهم لأعلى مع نسبة مئوية بالوردي/الكهرماني (تنبيه للمستخدم).

## 2. مخطط توزيع المصاريف حسب التصنيف (Category Breakdown Chart)

### نوع الرسم البياني المعتمد:
- **مخطط الدونات الدائري (Donut Chart)** مبني بمكتبة **Recharts**.
- **النسبة البصرية**: حلقة دائرية متوازنة مع إبراز النسبة المئوية وقيمة التصنيف الأكبر في مركز الدائرة عند التمرير.
- **حد أقصى للشرائح**: يعرض أشهر 5 إلى 6 تصنيفات إنفاقاً، وتُجمع باقي التصنيفات الصغيرة في شريحة محايدة باسم («أخرى»).
- **لوحة الألوان**: تعتمد ألوان التصنيفات المعرفة في `colors.md` مع فواصل بيضاء دقيقة (`2px`) بين الشرائح لضمان وضوح الحدود.

### البديل النصي الإلزامي (A11y Accessible Fallback):
مخططات الدونات وحدها لا تكفي لقارئات الشاشة أو ضعاف البصر. يُعرض أسفل الرسم **جدول تفصيلي مرتب تنازلياً** يحتوي على:
- اسم التصنيف مع أيقونته ولونه.
- المبلغ الإجمالي المصروف.
- النسبة المئوية الدقيقة من إجمالي نفقات الشهر.
- عدد المعاملات المسجلة في هذا التصنيف.

## 3. مخطط التدفق النقدي الشهري (Cash Flow Trend Chart)

### نوع الرسم البياني المعتمد:
- **مخطط الأعمدة المزدوجة المتجاورة (Grouped Bar Chart)** لمقارنة الدخل والمصروف أسبوعاً بأسبوع أو شهراً بشهر:
  - العمود الأخضر: إجمالي الدخل للحقبة.
  - العمود الوردي/القرمزي: إجمالي المصروف للحقبة.
- **خصائص الأعمدة**: زوايا علوية مدورة (`rounded-t: 4px`) لمنح الرسم طابعاً عصرياً هادئاً.
- **التفاعل (Tooltip)**: عند تمرير الماوس أو لمس العمود، تظهر بطاقة معلومات مصغرة تعرض:
  - التاريخ / الأسبوع.
  - الدخل والمصروف وصافي الفائض لتلك الفترة.

## 4. معالجة حالات البيانات الخاصة (Edge Cases in Data Viz)

### أ. حالة عدم وجود بيانات (Empty Data State):
- إذا لم تكن هناك أي مصاريف مسجلة للشهر المحدد:
  - **يُمنع منعاً باتاً عرض دائرة رمادية فارغة ميتة**.
  - يتم استبدال مساحة الرسم البياني بكتلة إرشادية أنيقة تحتوي على أيقونة دفتر مالي ورسالة تشجيعية: («لا توجد مصاريف مسجلة لهذا الشهر بعد — ابدأ بتسجيل أول مصروف للبدء في رؤية تحليلاتك»).

### ب. حالة المعاملة الواحدة (Single Transaction):
- إذا سجل المستخدم معاملة واحدة فقط، تظهر كحلقة دونات كاملة موحدة بلون ذلك التصنيف مع نص يوضح أن هذا التصنيف يمثل 100% من نفقات الشهر.

### ج. التعامل مع الالتزامات والأرصدة السالبة:
- في بطاقات الائتمان، المبالغ المدينة لا تعرض كخطأ أو كسر مالي؛ بل تعرض بوضوح كرصيد مدين محدد («المبلغ المستحق: 1,800 ر.س») مع توضيح تاريخ الاستحقاق.
